### [CityCrimes — Urban Crime Analytics Platform](https://citycrimes.io)
[![Live Demo](https://img.shields.io/badge/🌐_Live_Demo-E53935?style=for-the-badge)](https://citycrimes.io)
[![GitHub](https://img.shields.io/badge/GitHub-121011?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Sanmay-Das/CityCrimes)

Full-stack crime analytics platform serving ~70ms p50 queries over 10.8M+ records across 3 cities (LA, Chicago, NYC). Go GraphQL backend over PostgreSQL with R-tree spatial joins, React/TypeScript frontend with MapLibre GL, and a production RAG pipeline combining Text-to-SQL with Nomic AI vector search for natural-language queries.

**Stack:** Go • GraphQL • PostgreSQL • React • TypeScript • Groq • Nomic AI • Docker

### [LLM Serving Benchmark](https://github.com/Sanmay-Das/LLM-Serving-Benchmark)
[![GitHub](https://img.shields.io/badge/GitHub-121011?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Sanmay-Das/LLM-Serving-Benchmark)

Benchmarked vLLM, Ollama, and Ray Serve on a self-managed 3-node Kubernetes cluster with TinyLlama 1.1B. vLLM achieved 57% higher throughput and 38% lower latency than Ollama. Full Prometheus/Grafana observability stack.

**Stack:** Kubernetes • vLLM • Ollama • Ray Serve • Prometheus • Grafana • Locust

### [FutureFarmNow — Geospatial Data Platform](https://ffn.cs.ucr.edu/)
[![Live Demo](https://img.shields.io/badge/🌐_Live_Demo-4CAF50?style=for-the-badge)](https://ffn.cs.ucr.edu/)

**Stack:** Python • Flask • Docker • GDAL • GeoPandas • SQLite

### [LLVM Pass Development](https://github.com/Sanmay-Das/LLVM-Pass-Development)
[![GitHub](https://img.shields.io/badge/GitHub-121011?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Sanmay-Das/LLVM-Pass-Development)

12 LLVM analysis, transformation, and CFG passes in C++ targeting LLVM 19 — including OpcodeCounter, DynamicCallCounter, MBASub/MBAAdd (Mixed Boolean Arithmetic), and RIV. Out-of-tree build with CMake, LIT test suites, and Dockerfiles for Ubuntu, Fedora, and Arch Linux.

**Stack:** C++ • LLVM 19 • CMake • LIT • GDB/LLDB • Docker
